# math-calculator
Python scripts to add and square numbers


A simple two-file Python project that adds two numbers and squares the sum.

## Files
- `add_numbers.py`: Contains `get_sum()` to take two user inputs and return their sum.
- `square_number.py`: Imports `get_sum()` and prints the square of the result.

## How to Run
```bash
python square_number.py
